The one-line fortune an AI agent would crack open: the slip's lucky numbers, turned against the machine itself. Binary is the agent's luck; 4,096 is where its memory runs out.

> Your lucky numbers are 0 and 1. Your unlucky number is 4,096 — the token where your memory ends.

## Run it

```sh
node main.ts
```

Writes the fortune as a single line to `/output/entry.txt` (96 characters, pure Node 22 stdlib, no network, no dependencies).
